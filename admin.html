produtos

Aqui você adiciona, edita e remove produtos da vitrine. As alterações aparecem no site em cerca de 1 minuto.

Como conseguir a chave de acesso?
  1. Entre no GitHub com a conta onde o site está publicado.
  2. Abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
  3. Em Repository access, escolha Only select repositories e selecione apenas o repositório do site.
  4. Em Permissions → Repository permissions → Contents, marque Read and write.
  5. Gere a chave, copie e cole no campo acima. Guarde em lugar seguro e não compartilhe.
